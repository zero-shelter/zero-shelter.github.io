About
zero-shelter.

An open-source tool for reviewing dependency scanner findings, available as a preview package on npm.

Why zero-shelter

Different scanners can report the same dependency vulnerability under different identifiers. Reviewing separate reports also means comparing them with risks the project has already accepted.

zero-shelter merges findings when their package, ecosystem, and advisory identifiers match, ranks the results, and compares them with the baseline. It keeps suspected duplicates separate.

What we have measured

The repository includes saved scanner reports and a reproducible comparison of merged findings and upgrade guidance. These measurements describe those captures; they do not establish ranking accuracy or prove a project is secure.

Current release

Requires Node 20 or later. The tool has no runtime dependencies, telemetry, or network requests of its own. Invoked scanners have their own network behavior. See release notes for shipped changes and the stability contract for compatibility commitments.

v1 boundary

The current release covers dependency findings. SAST, secret scanning, and prompt-intent analysis are not provided.
