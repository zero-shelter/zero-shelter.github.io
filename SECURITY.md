# Security Policy

## Reporting a vulnerability

Do not report website vulnerability details through public Issues, Pull Requests, or Discussions.

Report security issues affecting this website through Private Vulnerability Reporting in [`zero-shelter/zero-shelter.github.io`](https://github.com/zero-shelter/zero-shelter.github.io/security/advisories).

If private reporting is unavailable, open a public Issue only to request a private security contact.
Do not include vulnerability details in that Issue.
