# zero-shelter.github.io

Official website for zero-shelter.

This repository hosts the public landing page and documentation entry point for
zero-shelter. Product source code, security reports, and internal operating
procedures do not belong here.

## Initial publishing scope

- Project introduction and status
- Links to public repositories and any community channel enabled in the future
- Installation and documentation links after the npm package is released
- Security reporting guidance without sensitive details

Before publishing, configure GitHub Pages for this repository and verify the
organization site URL: `https://zero-shelter.github.io`.

Website issues are tracked in the public
[Website Operations](https://github.com/orgs/zero-shelter/projects/2) project.
Use the repository's Website bug or Website change Issue Form so that scope,
acceptance criteria, accessibility impact, and validation remain explicit.
