Local-first dependency judgement

Dependency findings,
made actionable.

A local, deterministic judgement of dependency findings — what to fix now, and why.

  • Run locally
  • Node 20+
  • No runtime dependencies
  • Same input, same result
  • No runtime telemetry

Make the next action clear.

The same judgement moves from terminal to CI and an agent without a second ranking system.

See how it works →
  1. 01Read the findings

    npm audit always runs; add osv-scanner for a second source.

  2. 02Remove the overlap

    Join shared identifiers and leave uncertain matches visible.

  3. 03Keep the next fix

    Offer a command you can defend, then keep accepted work out of the next run.
