In practice

One signal,
three workspaces.

Carry the same judgement from a first local scan into CI and your coding agent.

/01

Terminal

Run the first scan with Node 20+ and a readable lockfile.

npx zero-shelter judge

/02

CI

Record the inherited backlog, upload SARIF, and fail on new findings.

npx zero-shelter judge --format sarif

/03

Coding agent

Give an agent the same findings and safe remediation context before it edits dependencies.

npx zero-shelter hook

Start with one run

From first scan
to quieter CI.

Review the initial backlog. Record it only when it is understood; later runs focus on what changed.

  1. 01

    Inspect

    A readable lockfile is required. No scanner report is exit 2, not a clean pass.

  2. 02

    Record

    Store inherited findings once; an expiry or new finding keeps the work visible.

  3. 03

    Gate

    Write SARIF for GitHub Code Scanning and use the judgement result to fail on new findings.

Agent route

Context, not control.

The hook adds the current judgement and commands to the session. It never blocks or rewrites a prompt and stays quiet on errors.

Claude Code plugin

Install five presentation-only skills for setup, explanation, fixes, baseline, and CI.

{
  "hooks": {
    "UserPromptSubmit": [
      { "hooks": [{ "type": "command", "command": "npx zero-shelter hook" }] }
    ]
  }
